# Photos of the demo's fictional people

The faces in this folder are AI-generated by https://thispersondoesnotexist.com and depict no real person. They illustrate the fictional shareholders and officers of the demo companies (`index.ts`), resized to 256 x 256 and compressed (JPEG quality 70).

`photos.ts` holds the same images as data URLs, the format Kledg stores in `Person.photo`; `lib/demo/__tests__/people.test.ts` checks that both agree.
